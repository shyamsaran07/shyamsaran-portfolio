Project Overview

Customer insights help businesses understand how customers purchase products and how much they spend. This project demonstrates basic analysis using an illustrative customer dataset.

Sample Dataset

These are fictional example records for demonstrating data analysis. They are not actual customer transactions.

Customer Orders Average Order Value (₹) Total Spending (₹)
Customer A 3 500 1500
Customer B 5 800 4000
Customer C 2 400 800
Customer D 6 1000 6000
Customer E 4 650 2600

Python Code

This example calculates customer spending and identifies the highest-spending customer. 

import pandas as pd

data = {
    "Customer": ["A", "B", "C", "D", "E"],
    "Orders": [3, 5, 2, 6, 4],
    "Average_Order_Value": [500, 800, 400, 1000, 650]
}

df = pd.DataFrame(data)

df["Total_Spending"] = (
    df["Orders"] * df["Average_Order_Value"]
)

print("Customer Dataset")
print(df)

print("\nTotal Customer Spending:")
print(df["Total_Spending"].sum())

print("\nAverage Customer Spending:")
print(round(df["Total_Spending"].mean(), 2))

print("\nHighest Spending Customer:")
print(
    df.loc[
        df["Total_Spending"].idxmax()
    ]
)

print("\nCustomers Sorted by Spending:")
print(
    df.sort_values(
        by="Total_Spending",
        ascending=False
    )
)

Key Findings

  • The illustrative dataset contains five customers.
  • Total spending across the sample is ₹14,900.
  • Average spending per customer is ₹2,980.
  • Customer D has the highest total spending in this sample.

These findings apply only to the sample data. Real business decisions would require a larger, representative dataset.
