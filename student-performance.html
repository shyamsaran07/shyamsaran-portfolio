DATA ANALYTICS PROJECT

Student Performance Analysis.

An educational data analysis demonstration exploring how study hours and attendance relate to student scores.

Python Data Analysis Education

Project Overview

This project uses a small illustrative dataset to demonstrate how student scores can be summarized and compared with study hours and attendance.

Sample Dataset

The following values are fictional examples created for demonstrating data analysis. They are not actual student records.

Student Study Hours Attendance (%) Score (%)
Student A 2 70 55
Student B 4 80 68
Student C 5 85 76
Student D 7 90 88
Student E 3 75 62

Python Code

The following Python example calculates the average score and compares study hours with scores. 

import pandas as pd

data = {
    "Student": ["A", "B", "C", "D", "E"],
    "Study_Hours": [2, 4, 5, 7, 3],
    "Attendance": [70, 80, 85, 90, 75],
    "Score": [55, 68, 76, 88, 62]
}

df = pd.DataFrame(data)

print("Student Performance Dataset")
print(df)

print("\nAverage Score:")
print(df["Score"].mean())

print("\nAverage Attendance:")
print(df["Attendance"].mean())

print("\nStudy Hours and Scores:")
print(df[["Study_Hours", "Score"]])

correlation = df["Study_Hours"].corr(df["Score"])

print("\nStudy Hours / Score Correlation:")
print(round(correlation, 2))

Key Findings

  • The sample dataset contains five illustrative students.
  • The average score is 69.8 out of 100.
  • The average attendance is 80%.
  • The example shows a positive relationship between study hours and scores.

These results describe only the illustrative sample. They do not establish that study hours alone determine academic performance.
